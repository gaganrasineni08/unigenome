## 1. A QR scanned twice (a copied QR) gets flagged

**How to show it**

1. Seller side: sell one item at the retailer (Shelf → Sell). Copy that item's QR link.
2. Buyer A: open the link, and type the hidden code to claim the item. The verdict is Genuine.
3. Buyer B: open the same link in a private (incognito) window. That counts as a different phone.
4. The verdict is **Suspicious clone: already claimed by a buyer**. The regulator's Alerts tab shows a new 'clone' alert at the top.

A second way to show it: scan in one city, then set the browser location far away (Chrome DevTools → Sensors) and scan again. The second scan is flagged as impossible travel.

One honest point to make: scanning twice **from the same phone in the same place is not flagged**. A shopper often scans twice. The system flags a second scan only when it shows a copy: another phone after the item was claimed, travel that is too fast, a scan far from the shop, or too many phones.

### 1.5 Check 2: impossible travel since the last scan

[server/logic.ts:302-313](../server/logic.ts#L302)

**DSA topic:** 3. Hash map / hash set, 13. Haversine distance + speed check

```ts
const last = ix.lastSeen.get(row.id);

  const km = haversineKm(last, here);
  const speed = impliedSpeedKmh(last, here);
  // Under 5 km is GPS noise or the same neighbourhood, whatever the time gap.
  const ok = km < 5 || speed <= MAX_SPEED_KMH;
  checks.push({ tier: "T1", ok, label: "Travel since last scan is physically possible", detail: km < 5 ? "same area as the last scan" : `${Math.round(km)} km, ${Number.isFinite(speed) ? Math.round(speed) + " km/h" : "no time between scans"}` });

    clone = true;
    reasons.push("scanned too far from its last scan in too little time");

```

`ix.lastSeen` is our own **hash map** (unit id → where and when it was last scanned). Looking up the last scan is O(1) on average, so this check stays fast with millions of items.

`haversineKm` gives the distance on the Earth's surface between the last scan and this one. `impliedSpeedKmh` divides it by the time between the scans.
If the item would have had to travel faster than **900 km/h** (`MAX_SPEED_KMH`, faster than a plane), one physical pack cannot be in both places: the QR was copied. Under 5 km is treated as GPS noise.

## 2. A fake or edited QR is caught as counterfeit

**How to show it**

Take any item's QR link, change one character in the part after `#`, and open it. The verdict is **Counterfeit**.
Even with no internet, the first check runs on the phone.

### 2.1 On the phone, even offline: check the signature

[src/pages/portals/Buyer.tsx:37-48](../src/pages/portals/Buyer.tsx#L37)

**DSA topic:** 2. Digital signatures (Ed25519), 3. Hash map / hash set

```tsx
function offlineCheck(text: string, k: Awaited<ReturnType<typeof keys>>) {
  let u: SignedUnit;
  try {
    u = decodePayload(payloadFromScan(text));
  } catch {
    return { ok: false, label: "Not a UniGenome code", unit: null };
  }
  const p = k.parties.find((x) => x.id === signerOf(u.f));
  if (!p) return { ok: false, label: "Unknown signer", unit: u };
  if (k.revoked.includes(p.id)) return { ok: false, label: "Signer's key was revoked", unit: u };
  return { ok: verifyUnit(u, p.publicKey), label: verifyUnit(u, p.publicKey) ? `Signed by ${p.name}` : "Signature does not match", unit: u };
}
```

The phone keeps a copy of every company's **public key**. It decodes the QR, finds the company that signed it, and checks the **Ed25519 signature**.
If anyone changes even one character of the QR (product, batch, expiry), the signature no longer matches. Making a valid signature needs the manufacturer's private key, which never leaves their browser.

### 2.3 The item's fingerprint (DNA0) and its signature

[shared/identity.ts:35-43](../shared/identity.ts#L35)

**DSA topic:** 1. SHA-256 hashing, 2. Digital signatures (Ed25519)

```ts
export const dnaOf = (f: UnitFields): string => hashOf(DOMAIN[f.kind], f);

export function signUnit(f: UnitFields, secretKeyHex: string): SignedUnit {
  return { f, sig: signMessage(DOMAIN[f.kind], { dna: dnaOf(f) }, secretKeyHex) };
}

export function verifyUnit(u: SignedUnit, signerPublicKeyHex: string): boolean {
  return verifyMessage(DOMAIN[u.f.kind], { dna: dnaOf(u.f) }, u.sig, signerPublicKeyHex);
}
```

`dnaOf` is the **SHA-256 hash** of all the item's details (product, batch, dates, and a random salt). Change one letter and the hash changes completely.
`signUnit` signs that hash with the manufacturer's private key. `verifyUnit` checks it with the public key.

### 2.4 Signing and verifying (Ed25519)

[shared/crypto.ts:26-38](../shared/crypto.ts#L26)

**DSA topic:** 2. Digital signatures (Ed25519)

```ts
export function signMessage(domain: string, body: unknown, secretKeyHex: string): string {
  const msg = utf8(domain + "\n" + canonical(body));
  return toB64url(ed25519.sign(msg, fromHex(secretKeyHex)));
}

export function verifyMessage(domain: string, body: unknown, sigB64: string, publicKeyHex: string): boolean {
  try {
    const msg = utf8(domain + "\n" + canonical(body));
    return ed25519.verify(fromB64url(sigB64), msg, fromHex(publicKeyHex));
  } catch {
    return false;
  }
}
```

Each message starts with a **domain tag** such as `UG/item` or `UG/event`, so a signature made for one purpose can never be reused for another.
`canonical(body)` writes the object with sorted keys, so the same data always gives the same bytes.

### 3.2 Encrypting the private key with the passphrase

[shared/keystore.ts:26-33](../shared/keystore.ts#L26)

**DSA topic:** 1. SHA-256 hashing

```ts
export async function encryptSecretKey(secretKeyHex: string, passphrase: string): Promise<EncryptedKey> {
  const salt = randomBytes(16);
  const iv = randomBytes(12);
  const iter = 200_000;
  const key = await deriveKey(passphrase, salt, iter);
  const ct = new Uint8Array(await subtle().encrypt({ name: "AES-GCM", iv: iv as BufferSource }, key, fromHex(secretKeyHex) as BufferSource));
  return { v: 1, salt: toB64url(salt), iv: toB64url(iv), ct: toB64url(ct), iter };
}
```

The passphrase is stretched with **PBKDF2 (SHA-256, 200,000 rounds)** into an AES key. This makes guessing passphrases slow.

### 3.4 Checking the GSTIN check digit

[shared/gstin.ts:8-15](../shared/gstin.ts#L8)

```ts
export function gstinCheckChar(first14: string): string {
  let sum = 0;
  for (let i = 0; i < 14; i++) {
    const p = CHARS.indexOf(first14[i]) * (i % 2 ? 2 : 1);
    sum += Math.floor(p / 36) + (p % 36);
  }
  return CHARS[(36 - (sum % 36)) % 36];
}
```

The last character of a GSTIN is a **check digit** computed from the first 14 (a mod-36 weighted sum). A typo or a made-up GSTIN almost always fails this.

```ts
export function buildLevels(leafIds: string[]): string[][] {
  if (leafIds.length === 0) throw new Error("empty Merkle tree");
  const levels: string[][] = [leafIds.map(leafHash)];
  while (levels[levels.length - 1].length > 1) {
    const prev = levels[levels.length - 1];
    const next: string[] = [];
    for (let i = 0; i < prev.length; i += 2) next.push(nodeHash(prev[i], prev[i + 1] ?? prev[i]));

}
```

### 7.5 Expected arrival with Dijkstra

[server/logic.ts:162-192](../server/logic.ts#L162)

```ts
export async function routeGraph() {
  const d = await db();
  const rows = await d.query(
    `SELECT from_party, to_party, AVG((received_ts - dispatched_ts) / 3600000.0) AS hours,
            STDDEV_SAMP((received_ts - dispatched_ts) / 3600000.0) AS sd, COUNT(*) AS n
       FROM shipments WHERE status = 'received' AND received_by = to_party GROUP BY from_party, to_party`,
  );
  const g = new Graph();
  for (const r of rows) g.addEdge(r.from_party, r.to_party, Number(r.hours));
  return { g, rows };
}

export async function estimateArrival(from: string, to: string) {
  const { g, rows } = await routeGraph();
  if (g.adj.has(from)) {
    const r = dijkstra(g, from);
    const hours = r.dist[to];
    if (Number.isFinite(hours)) {
      const path = r.pathTo(to);
      // Margin from the spread actually seen on the direct route, or half the estimate.
      const direct = rows.find((x) => x.from_party === from && x.to_party === to);
      const margin = direct && Number(direct.n) >= 3 && direct.sd ? 2 * Number(direct.sd) : Math.max(6, hours * 0.5);
      return { hours, path, method: "dijkstra" as const, marginHours: margin };
    }
  }
  const a = await mainSite(from);
  const b = await mainSite(to);
  const km = a && b ? haversineKm(a, b) : 300;
  const hours = 12 + km / 40; // handling time plus an average road speed
  return { hours, path: [from, to], method: "distance" as const, marginHours: Math.max(6, hours * 0.5) };
}
```

Past deliveries form a **weighted graph**: companies are nodes, and each edge's weight is the average hours a delivery took.
**Dijkstra** (using a min-**heap**) finds the fastest known route. With no history yet, it falls back to haversine distance ÷ road speed.

### 7.6 Dijkstra's algorithm

[shared/dsa/graph.ts:54-84](../shared/dsa/graph.ts#L54)

**DSA topic:** 8. Dijkstra's shortest path, 9. Binary heap (priority queue)

```ts
export function dijkstra(g: Graph, src: string) {
  const dist = new Map<string, number>();
  const prev = new Map<string, string>();
  const settled: string[] = [];
  for (const n of g.nodes) dist.set(n, Infinity);
  dist.set(src, 0);
  const heap = new BinaryHeap<[number, string]>((a, b) => a[0] < b[0]);
  heap.push([0, src]);
  const done = new Set<string>();
  while (heap.size) {
    const [d, u] = heap.pop()!;
    if (done.has(u)) continue; // stale heap entry
    done.add(u);
    settled.push(u);
    for (const { to, w } of g.adj.get(u) ?? []) {
      const nd = d + w;
      if (nd < (dist.get(to) ?? Infinity)) {
        dist.set(to, nd);
        prev.set(to, u);
        heap.push([nd, to]);
      }
    }
  }
  const pathTo = (t: string): string[] => {
    if (!Number.isFinite(dist.get(t) ?? Infinity)) return [];
    const p = [t];
    while (p[0] !== src) p.unshift(prev.get(p[0])!);
    return p;
  };
  return { dist: Object.fromEntries(dist), pathTo, settled };
}
```

Always settle the closest unsettled node (taken from the heap), then relax its edges. O((V + E) log V).

### 8.5 Depth-first search with a stack

[shared/dsa/tree.ts:4-14](../shared/dsa/tree.ts#L4)

**DSA topic:** 6. Tree + DFS

```ts
export function dfsCollect(root: string, children: (id: string) => string[]): string[] {
  const order: string[] = [];
  const stack = [root];
  while (stack.length) {
    const u = stack.pop()!;
    order.push(u);
    const kids = children(u);
    for (let i = kids.length - 1; i >= 0; i--) stack.push(kids[i]); // keep left-to-right order
  }
  return order;
}
```

Pop a unit, record it, push its children. Every unit below the root is visited once: O(n).

```ts
export function merkleProof(leafIds: string[], index: number): ProofStep[] {
  const levels = buildLevels(leafIds);
  const proof: ProofStep[] = [];
  let i = index;
  for (let lv = 0; lv < levels.length - 1; lv++) {
    const level = levels[lv];
    const isRight = i % 2 === 1;
    const sib = isRight ? level[i - 1] : level[i + 1] ?? level[i];
    proof.push({ hash: sib, side: isRight ? "L" : "R" });
    i = Math.floor(i / 2);
  }
  return proof;
}

export function verifyProof(leafId: string, proof: ProofStep[], root: string): boolean {
  let h = leafHash(leafId);
  for (const step of proof) h = step.side === "L" ? nodeHash(step.hash, h) : nodeHash(h, step.hash);
  return h === root;
}
```

```ts
export function kWayMerge<T>(lists: T[][], key: (x: T) => number): T[] {
  const heap = new BinaryHeap<{ v: T; li: number; i: number }>((x, y) => key(x.v) < key(y.v));
  lists.forEach((l, li) => l.length && heap.push({ v: l[0], li, i: 0 }));
  const out: T[] = [];
  while (heap.size) {
    const { v, li, i } = heap.pop()!;
    out.push(v);
    if (i + 1 < lists[li].length) heap.push({ v: lists[li][i + 1], li, i: i + 1 });
  }
  return out;
}
```

Each list contributes its next record when its current one is taken.

### 11.2 Heap push (sift up) and pop (sift down)

[shared/dsa/heap.ts:17-47](../shared/dsa/heap.ts#L17)

**DSA topic:** 9. Binary heap (priority queue)

```ts
push(x: T) {
  this.a.push(x);
  let i = this.a.length - 1;
  while (i > 0) {
    const p = (i - 1) >> 1;
    if (!this.less(this.a[i], this.a[p])) break;
    [this.a[i], this.a[p]] = [this.a[p], this.a[i]];
    i = p;
  }
}

pop(): T | undefined {
  const n = this.a.length;
  if (n === 0) return undefined;
  const top = this.a[0];
  const last = this.a.pop()!;
  if (n > 1) {
    this.a[0] = last;
    let i = 0;
    for (;;) {
      const l = 2 * i + 1;
      const r = l + 1;
      let best = i;
      if (l < this.a.length && this.less(this.a[l], this.a[best])) best = l;
      if (r < this.a.length && this.less(this.a[r], this.a[best])) best = r;
      if (best === i) break;
      [this.a[i], this.a[best]] = [this.a[best], this.a[i]];
      i = best;
    }
  }
  return top;
```

Children of index i are 2i+1 and 2i+2. Push and pop are O(log n), and the most urgent alert is always at index 0.

### 13.2 Breadth-first search with a queue

```ts
export function bfs(g: Graph, start: string) {
  const dist = new Map<string, number>([[start, 0]]);
  const order: string[] = [];
  const steps: BfsStep[] = [];
  const queue: string[] = [start];
  let head = 0; // index of the queue's front, so dequeue is O(1)
  while (head < queue.length) {
    const u = queue[head++];
    order.push(u);
    for (const { to } of g.adj.get(u) ?? []) {
      if (!dist.has(to)) {
        dist.set(to, dist.get(u)! + 1);
        queue.push(to);
      }
    }
    steps.push({ visit: u, queue: queue.slice(head) });
  }
  return { order, dist: Object.fromEntries(dist), steps };
}
```

O(V + E). `head` moves forward so dequeue is O(1).

### 13.4 The DP table

[shared/dsa/knapsack.ts:23-61](../shared/dsa/knapsack.ts#L23)

```ts
export function knapsack2D(items: Candidate[], budget: number, staff: number) {
  const n = items.length;
  const B = Math.max(0, Math.floor(budget));
  const S = Math.max(0, Math.floor(staff));
  const dp: number[][][] = Array.from({ length: n + 1 }, () =>
    Array.from({ length: B + 1 }, () => new Array<number>(S + 1).fill(0)),
  );
  for (let i = 1; i <= n; i++) {
    const it = items[i - 1];
    for (let b = 0; b <= B; b++) {
      for (let s = 0; s <= S; s++) {
        let best = dp[i - 1][b][s]; // skip candidate i
        if (it.cost <= b && it.staff <= s) best = Math.max(best, dp[i - 1][b - it.cost][s - it.staff] + it.risk);
        dp[i][b][s] = best;
      }
    }
  }
  // Walk back through the table to recover which candidates were taken.
  const chosen: string[] = [];
  let b = B;
  let s = S;
  for (let i = n; i >= 1; i--) {
    if (dp[i][b][s] !== dp[i - 1][b][s]) {
      const it = items[i - 1];
      chosen.unshift(it.id);
      b -= it.cost;
      s -= it.staff;
    }
  }
  const pick = items.filter((x) => chosen.includes(x.id));
  const result: Allocation = {
    chosen,
    risk: dp[n][B][S],
    cost: pick.reduce((a, x) => a + x.cost, 0),
    staff: pick.reduce((a, x) => a + x.staff, 0),
  };
  const table = dp.map((layer) => layer.map((row) => row[S])); // rows: i, columns: budget b
  return { result, table, cells: (n + 1) * (B + 1) * (S + 1) };
}
```

dp[i][b][s] = max(skip site i, take site i). O(n · B · S). Walking back through the table recovers which sites were chosen.

```ts
search(prefix: string, limit = 20): { total: number; keys: string[]; path: string[] } {
  const p = prefix.toUpperCase();
  const start = this.walk(p);
  if (!start) return { total: 0, keys: [], path: [] };
  const keys: string[] = [];
  const stack: Array<[Node, string]> = [[start, p]];
  while (stack.length && keys.length < limit) {
    const [n, s] = stack.pop()!;
    if (n.end) keys.push(s);
    const kids = [...n.children.entries()].sort((a, b) => (a[0] < b[0] ? 1 : -1));
    for (const [ch, c] of kids) stack.push([c, s + ch]);
  }
  return { total: start.count, keys, path: [...p] };
}
```

```ts
insert(key: string, value: V) {
  const ins = (n: Node<V> | null): Node<V> => {
    if (!n) return { key, values: [value], left: null, right: null, height: 1 };
    if (key === n.key) {
      n.values.push(value);
      return n;
    }
    if (key < n.key) n.left = ins(n.left);
    else n.right = ins(n.right);
    fix(n);
    const b = balanceOf(n);
    if (b > 1) {
      if (key > n.left!.key) n.left = this.rotLeft(n.left!); // left-right case
      return this.rotRight(n);
    }
    if (b < -1) {
      if (key < n.right!.key) n.right = this.rotRight(n.right!); // right-left case
      return this.rotLeft(n);
    }
    return n;
  };
  this.root = ins(this.root);
}
```

After each insert the tree re-balances with rotations, so its height stays O(log n).
